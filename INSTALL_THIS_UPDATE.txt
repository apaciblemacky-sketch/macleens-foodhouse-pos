2. Keep the hidden .git folder and any private .env file.
3. Copy every item from this ZIP into that folder and approve Replace All.
4. Double-click RUN_MACLEENS.bat and test locally.
5. Double-click DEPLOY_TO_RENDER.bat; type DEPLOY when prompted.
6. Wait for Render to show Live. Open /healthz and confirm release:
