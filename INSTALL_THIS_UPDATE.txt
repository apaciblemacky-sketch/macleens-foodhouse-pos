INSTALL AND DEPLOY
1. Open the local GitHub-connected Macleen's project folder.
2. Keep the hidden .git folder and any private .env file.
3. Copy all contents of this ZIP into that project folder and approve Replace All.
4. Double-click RUN_MACLEENS.bat to test locally.
5. Double-click DEPLOY_TO_RENDER.bat and type DEPLOY when prompted.
6. After Render reports a successful deployment, test:
   Storefront: https://macleens-foodhouse-pos.onrender.com/
   Rewards:    https://macleens-foodhouse-pos.onrender.com/portal/dashboard
   Digital:    https://macleens-foodhouse-pos.onrender.com/digital
   Health:     https://macleens-foodhouse-pos.onrender.com/healthz
